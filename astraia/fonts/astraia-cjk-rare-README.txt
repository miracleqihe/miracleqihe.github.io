Astraia CJK Supplemental Rare

Renamed subset of Adobe Source Han Serif Regular and Bold, version 1.001,
covering U+62B2. The original fonts and this modified subset use the SIL Open
Font License 1.1; see astraia-cjk-supplement-LICENSE.txt. The reserved font
name is not used for this subset.

Source font SHA-256 values and upstream source are documented in
astraia-cjk-supplement-README.txt.
